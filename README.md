# מודע - אבטיפוס MVP

האבטיפוס נמצא בקובץ `index.html` ואפשר לפתוח אותו ישירות בדפדפן.

מה כלול:

- ווידג׳ט בעברית עם כפתורי הכנסה/הוצאה.
- מחשבון מהיר עם Enter להוספה.
- החלפת מטבע: שקל, באט תאילנדי, דולר אמריקאי, יורו.
- יעד חצי-חודשי וחישוב קצב יומי.
- משפט מודעות שמסביר איפה המשתמש עומד עכשיו.
- רשימת פעולות שנשמרת ב-localStorage.
- תזכורת חצי-חודשית בדמו עם צליל, שכבת מסך והחלקה לכיבוי.
- מסך Gmail במצב MVP: סריקת חודש מדומה, הצגת קבלות, אישור/דחייה.
- קבצי PWA להתקנה באייפון דרך Safari אחרי העלאה לשרת HTTPS.

התקנה באייפון בלי Mac:

1. העלה את תיקיית `outputs` לשירות HTTPS כמו Netlify, Vercel או GitHub Pages.
2. פתח את כתובת האתר באייפון דרך Safari.
3. לחץ Share.
4. בחר Add to Home Screen.
5. פתח את "מודע" מהאייקון החדש במסך הבית.

הערת Gmail:

באפליקציה אמיתית הכפתור "חבר" צריך לפתוח OAuth של Google, לקבל הרשאת Gmail מתאימה, להריץ חיפוש עם `q` לפי שולחים וטווח תאריכים, לשלוף הודעות, לזהות סכומים ותאריכים, ולהציג אותם לאישור לפני הכנסה לתקציב.
