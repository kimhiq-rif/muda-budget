# מודע - PWA למעקב הוצאות

אפליקציית Web בעברית שאפשר להוסיף למסך הבית באייפון דרך Safari.

## מה כלול

- ווידג׳ט פנימי עם כפתורי הכנסה/הוצאה.
- מחשבון מהיר.
- מטבעות: שקל, באט תאילנדי, דולר אמריקאי, יורו.
- יעד חצי-חודשי ומשפטי מודעות.
- רשימת פעולות שנשמרת מקומית בדפדפן.
- מסך Gmail אמיתי דרך Google Identity Services ו-Gmail API.
- סריקת מיילים מהחודש הנוכחי לפי כתובות שולחים.
- איסוף שקט של הוצאות מ-Gmail.
- מניעת כפילויות לפי מזהה הודעת Gmail וטביעת אצבע של חשבונית.
- הפרדה ברורה בין הוצאות היום לבין הוצאות לפני היום.
- צילום חשבוניות ושמירה בארכיון מקומי.
- חיפוש חשבונית לפי שם ופתיחת התמונה בלחיצה.
- דוח חצי-חודשי חוסם עם נתונים יבשים בלבד.

## התקנה באייפון

1. העלה את הקבצים ל-GitHub Pages.
2. פתח באייפון דרך Safari את כתובת GitHub Pages.
3. לחץ Share.
4. בחר Add to Home Screen.
5. פתח את "מודע" מהאייקון החדש.

## אם האייפון מציג גרסה ישנה

`https://kimhiq-rif.github.io/muda-budget/reset.html?v=8`

אחרי שהדף אומר שהניקוי הושלם, לחץ "פתח את מודע מחדש" והוסף שוב למסך הבית.

## שמירת נתונים באייפון

ב-iOS, טאב Safari ואפליקציה שנוספה למסך הבית יכולים להשתמש באחסון מקומי נפרד. לכן מומלץ:

1. קודם להוסיף את האפליקציה למסך הבית.
2. אחר כך לבצע את חיבור Gmail והסריקה מתוך האייקון במסך הבית.

אם כבר סרקת בטאב Safari ורוצה להעביר לאפליקציה:

1. בטאב Safari לחץ "גיבוי".
2. העתק את הקוד.
3. פתח את "מודע" ממסך הבית.
4. לחץ "ייבוא".
5. הדבק את הקוד.

## ארכיון תמונות

תמונות חשבוניות נשמרות מקומית במכשיר באמצעות IndexedDB. האפליקציה שומרת אותן עד שנתיים ומנקה תמונות ישנות יותר.

חשוב: התמונות לא עולות לענן בשלב הזה. אם מוחקים את נתוני האתר, מוחקים את האפליקציה, או עוברים מכשיר, התמונות המקומיות עלולות להימחק. לשמירה קשיחה לשנתיים בין מכשירים צריך בהמשך להוסיף backend או אחסון ענן מאובטח.

## הפעלת Gmail אמיתי

1. פתח Google Cloud Console.
2. צור Project חדש.
3. הפעל Gmail API.
4. עבור ל-OAuth consent screen.
5. הגדר App name: מודע.
6. User type: External.
7. הוסף את עצמך כ-Test user.
8. הוסף Scope:
   `https://www.googleapis.com/auth/gmail.readonly`
9. עבור ל-Credentials.
10. צור OAuth Client ID מסוג Web application.
11. תחת Authorized JavaScript origins הוסף:
   `https://kimhiq-rif.github.io`
12. העתק את ה-Client ID.
13. באפליקציה, בלשונית Gmail, הדבק את ה-Client ID. זה לא המייל שלך, אלא ערך שנראה בערך כך:
   `1234567890-abcdefg.apps.googleusercontent.com`
14. בשדה כתובות השולחים הזן כתובות מייל של קבלות, כל כתובת בשורה נפרדת.
15. לחץ "חבר", אשר הרשאת Gmail, ואז לחץ "סרוק חודש".

לשימוש אישי אפשר לעבוד במצב Testing עם המשתמש שלך כ-Test user. להפצה למשתמשים נוספים צריך אימות OAuth של Google ומדיניות פרטיות.
